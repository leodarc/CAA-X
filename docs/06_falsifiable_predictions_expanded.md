## 一、原19项预测回顾

V4 论文 Appendix B 已建立 19 项可证伪预测，覆盖认知原子、GWP、λ-序参量、认知流形等核心组件。本扩展表基于 2026年6月2-3日 前沿动态，新增 10 项预测，并对原预测进行补充说明。

## 二、新增预测（#20-#29）

### 预测 #20：Backpack sense vector 持久性分类

| 属性 | 内容 |
|------|------|
| **预测** | Backpack Models 的 sense vector 可按持久性（ephemeral/durable/permanent）分类，分类准确率 > 80% |
| **理论依据** | CAA-X 认知原子的持久性语义（Definition 2.2） |
| **实验方法** | 1. 提取 Backpack sense vector<br>2. 按激活频率/更新模式聚类<br>3. 人工标注验证 |
| **测量指标** | 分类准确率、F1-score |
| **证伪条件** | 分类准确率 < 60%，或 sense vector 无持久性差异 |
| **关联前沿** | Backpack Models (ACL 2023) |
| **优先级** | P1 |

### 预测 #25：Attention Sink 作为流形吸引子

| 属性 | 内容 |
|------|------|
| **预测** | Transformer 中的 Attention Sink 位置对应认知流形上的局部极小值（吸引子），且吸引子 basin 大小与模型容量正相关（r > 0.6） |
| **理论依据** | 认知流形动力学（Theorem 5.1） |
| **实验方法** | 1. 追踪注意力权重演化<br>2. 投影到认知流形<br>3. 计算局部极小值和 basin 大小 |
| **测量指标** | 吸引子位置对应率、basin 大小-容量相关性 |
| **证伪条件** | Sink 位置不对应局部极小值，或相关性 r < 0.3 |
| **关联前沿** | "What are you sinking?" (NeurIPS 2025) |
| **优先级** | P1 |
